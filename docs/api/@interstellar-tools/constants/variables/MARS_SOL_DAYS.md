# Variable: MARS_SOL_DAYS

```ts
const MARS_SOL_DAYS: 1.0274912517;
```

Defined in:
[temporal.ts:119](https://github.com/phun-ky/interstellar-tools/blob/main/packages/constants/src/temporal.ts#L119)

The **Martian sol** in Earth days: the ratio of a sol to a day, 1.0274912517.

::: info

- The Mars Sol Date counts sols by dividing a Julian date's days by it.
- Allison & McEwen (2000) give 1.02749125. This is the more precise value NASA
  GISS's Mars24 has used since 2015.

:::
