# Variable: EGM2008

```ts
const EGM2008: Readonly<{
  J: readonly number[];
  mu: number;
  radius: number;
}>;
```

Defined in:
[geodesy.ts:85](https://github.com/phun-ky/interstellar-tools/blob/main/packages/constants/src/geodesy.ts#L85)

**Earth's gravity field** from EGM2008, the Earth Gravitational Model of the US
National Geospatial-Intelligence Agency, to the sixth zonal harmonic: what a
numerical propagator needs beyond a point mass.

$$
J_n = -\sqrt{2n + 1}\;\bar C_{n,0}
$$

Where:

- $\bar C_{n,0}$ are the model's fully normalised zonal coefficients, tide-free
- $J_n$ are the unnormalised zonal harmonics, as `zonalHarmonicsAcceleration` in
  `@interstellar-tools/equations` takes them

::: info Notes

- `J` holds $J_2$ to $J_6$, in order. $J_2$, the equatorial bulge, is a thousand
  times the others: it turns orbit planes and perigees.
- Use `mu` and `radius` with these $J_n$: they were fitted together. The radius
  is EGM2008's reference radius, 0.7 m less than WGS 84's.
- Only the zonal terms, which don't vary with longitude. The full model goes to
  degree 2190, for geodesy.

:::

## See

- https://icgem.gfz-potsdam.de/tom_longtime ICGEM, where the EGM2008
  coefficients are served
- https://marees.obspm.fr/content/chapter6/icc6.pdf IERS Conventions (2010),
  chapter 6, on EGM2008's GM and radius

## Example

```ts
import { zonalHarmonicsAcceleration } from '@interstellar-tools/equations';

zonalHarmonicsAcceleration(r, EGM2008.mu, EGM2008.radius, EGM2008.J);
```
