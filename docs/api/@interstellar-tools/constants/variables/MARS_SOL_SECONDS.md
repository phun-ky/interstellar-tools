# Variable: MARS_SOL_SECONDS

```ts
const MARS_SOL_SECONDS: 88775.244;
```

Defined in:
[temporal.ts:102](https://github.com/phun-ky/interstellar-tools/blob/main/packages/constants/src/temporal.ts#L102)

The **Martian sol** in seconds: the mean solar day on Mars, sunrise to sunrise,
24 h 39 m 35.244 s.

::: info

- Rovers count their days on Mars in sols, from landing.
- It is [MARS_SOL_DAYS](MARS_SOL_DAYS.md) Earth days.

:::
